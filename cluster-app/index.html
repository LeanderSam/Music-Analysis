About Symphony

Symphony is an interactive music exploration tool that uses Unsupervised Machine Learning to discover patterns in audio data.

Using K-Means clustering, the app groups songs based on acoustic features like Danceability, Energy, and Loudness. You can dynamically adjust the number of clusters (K) and select different features for the axes to see how songs relate to each other in multi-dimensional space.
