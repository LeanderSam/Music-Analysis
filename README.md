# Unsupervised Learning Project – NOVA IMS

## Overview

This repository contains the practical component for the **Unsupervised Learning** course at NOVA IMS.
The objective of this project is to apply unsupervised machine learning algorithms to a real-world dataset and develop an interactive application to explore and visualize the results.

---

## Project Requirements

### 👥 Team

* 1 to 3 students

### 📊 Data

* Must use **real-world data** (no AI-generated or synthetic datasets)
* Acceptable sources:

  * Kaggle
  * UCI Machine Learning Repository
  * Open APIs
  * Custom web-scraped datasets

### 🤖 Algorithms

* Apply and visualize **at least two unsupervised learning algorithms**
* Examples include:

  * Clustering:

    * K-Means
    * DBSCAN
    * Hierarchical Clustering
  * Dimensionality Reduction:

    * PCA
    * t-SNE
    * UMAP

### 💻 Application

* Build a working prototype using:

  * Streamlit, React, or HTML/JavaScript
* The app should:

  * Clearly present findings
  * Be understandable to non-expert users

### 🧠 AI Assistance

* AI tools (e.g., ChatGPT, GitHub Copilot, Cursor, Claude) are allowed and encouraged
* However, full understanding of:

  * The algorithms
  * The implementation
  * The results
    is required
